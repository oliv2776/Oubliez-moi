Comment obtenir un identifiant d'application ?
  1. Microsoft exige une application déclarée dans un annuaire Microsoft Entra (celui de votre entreprise, ou un annuaire créé avec un compte Azure).
  2. Sur entra.microsoft.com → Applications → Inscriptions d'applications → Nouvelle inscription.
  3. Types de comptes : comptes de n'importe quel annuaire et comptes Microsoft personnels. Pas d'URI de redirection.
  4. Dans Authentification, activez Autoriser les flux clients publics.
  5. Copiez l'ID d'application (client) ici, enregistrez, puis cliquez sur « Connecter le compte Microsoft ».
