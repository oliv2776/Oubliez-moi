Comment obtenir un identifiant d'application ?
  1. Il faut un annuaire Microsoft Entra : celui de votre entreprise, ou celui que crée un compte Azure gratuit (azure.microsoft.com/free ; téléphone et carte bancaire demandés pour vérifier l'identité, rien n'est facturé). Avec un simple compte Hotmail, le portail Entra répond « le compte n'existe pas dans le client Microsoft Services ».
  2. Sur entra.microsoft.com, dans cet annuaire : Inscriptions d'applications → Nouvelle inscription.
  3. Types de comptes : comptes de n'importe quel annuaire et comptes Microsoft personnels. Pas d'URI de redirection.
  4. Dans Authentification, activez Autoriser les flux clients publics. Dans Autorisations d'API, ajoutez IMAP.AccessAsUser.All et offline_access (Microsoft Graph, déléguées).
  5. Copiez l'ID d'application (client) ici, enregistrez, puis cliquez sur « Connecter le compte Microsoft ».
