Remplir le formulaire en ligne
  1. Ouvrir le formulaire ↗ s'ouvre dans un nouvel onglet ; gardez celui-ci à côté
  2. Copiez chaque information dans le champ correspondant. Ne remplissez que ce que le formulaire demande. {% for label, value in form_help.fields %} {% endfor %}
    {{ label }}{{ value }}
  3. Choix habituels dans les listes : type de demande suppression (delete, erasure), vous êtes la personne concernée (data subject), pays de résidence dans l'Union européenne, réglementation RGPD (GDPR). S'il y a un champ libre, collez ce message : 
    {{ form_help.msg_fr if r.language == 'fr' else form_help.msg_en }}
  4. Si le site envoie un e-mail de confirmation, il arrivera sur l'adresse saisie dans le formulaire : cliquez sur le lien qu'il contient, sinon la demande n'est pas prise en compte.
  5. {% if r.status != 'sent' %}
    {% if next_url %}{% endif %}

    Le délai légal d'un mois démarre à ce moment-là ; la demande passera en « Sans réponse » s'il expire.

    {% else %}

    Formulaire marqué comme envoyé : réponse attendue avant le {{ r.due_at|d }}.

    {% endif %}
{% endif %}
